# BlockConfig for B2 (the R3-copy CFLB): "Benders friendly" formulation
# (wf has the BenFormBit, i.e. wf == 8).
#
# The "extra" field carries the configuration for the hidden
# BendersBFunction and its inner MCFBlock. BenForm requires it (CFLB throws
# if missing). The preferred form is
#
#  SimpleConfiguration< pair< Configuration * , Configuration * > >
#
# where:
#  - first  = R3-Block Cfg (SimpleConfiguration<int> or
#             SimpleConfiguration<pair<int,double>>): the int (wR3B) is
#             ignored (hidden inner MCF is always "flow relaxation"), the
#             double (slackBigMScale) scales the slack-arc cost when the
#             variant in use employs slack arcs. nullptr means "defaults".
#  - second = ComputeConfig of the BendersBFunction (cf.
#             BendersBFunction::set_ComputeConfig()): handles BF params and,
#             via the named map in its f_extra_Configuration, the
#             BlockConfig / BlockSolverConfig to be applied to the inner
#             MCFBlock (the "BlockSolverConfig" key being required because
#             BenForm needs a Solver registered to the inner Block).
#
# See CFLB::set_BlockConfig() comments for the legacy forms still accepted.
