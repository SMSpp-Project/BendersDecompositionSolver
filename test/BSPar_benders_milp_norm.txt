# A txt description of a BlockSolverConfig for a Block having a single
# BendersDecompositionSolver attached, in the MILP regime with the feasibility
# cuts normalized: the Farkas certificate they are made of is a ray, hence its
# scale is an accident of the subproblem Solver, and dividing it by a norm of
# its own coefficients puts all of them on the same footing. The half-spaces
# are the same, so the optimum has to be, too.

BendersDecompositionSolver # name of Solver

1  # number of ComputeConfig in this BlockSolverConfig

# now all the ComputeConfig
# 1st ComputeConfig - - - - - - - - - - - - - - - - - - - - - - - - - - - - -

ComputeConfig # exact type of the ComputeConfig object

0  # f_diff == 0 ==> all non-provided parameters are set to the default value

int_BDSlv_Regime  1  # 0 = convex master, 1 = MILP master
